# 心知天气完全上手指南（从注册到跑通第一个请求）

> 这一章独立成篇，因为它是整个项目里**唯一需要你去网站手动操作、且操作错了不报错只显示"--"**的环节。
> 别的环节写错了编译会报错，这里写错了板子照样正常跑，只是天气永远是空的——最难查。

---

## 0. 先看这个：你到底能拿到什么数据

心知天气的权限是**分档**的，不同档位返回的字段不一样。**这是最常见的"我代码没错但没数据"的原因。**

**本项目只用免费版（0 元永久），能拿到的数据是这些：**

| 数据项 | 免费版（0 元永久） | 说明 |
|---|---|---|
| 天气现象文字（晴/多云/雨…） | ✅ | `now.json` → `now.text` |
| 天气现象代码 | ✅ | `now.json` → `now.code`（本项目未用） |
| **实时气温** | ✅ | `now.json` → `now.temperature` |
| 今日最高/最低温 | ✅ | `daily.json` → `daily[0].high / low` |
| 今日风向风力 | ✅ | `daily.json` → `daily[0].wind_direction / wind_scale` |
| 城市覆盖 | 国内 370 个主要城市 | 够用 |
| 访问量 | 10 万次/月 | 本项目每天 96 次，离上限很远 |
| 频率 | 1 次/秒 | 本项目 15 分钟一次 |

**免费版拿不到、本项目也不显示的**：

| 数据项 | 状态 |
|---|---|
| 实时湿度 | ❌ 付费权限 |
| 体感温度 / 气压 / 能见度 | ❌ 付费权限 |
| 实时风速（只有预报的风向风力） | ❌ 付费权限 |

> 💡 **所以本项目界面显示的是**：天气现象 + 实时气温 + 今日温区 + 风向风力。
> **没有湿度** —— 不是 bug，是免费版权限。代码里干脆就不请求、不解析、不显示，
> 界面右侧留白给"风向风力"，比显示一个假的"湿--%"干净得多。

**如果哪天你想加湿度**：那是心知付费档位的事，届时要改两处 ——
`weather.c` 里加 `copy_str(d0, "humidity", ...)`，`ui.c` 里加显示分支。
但那是以后的事，现在完全不需要。

## 2. 添加产品、拿私钥

登录后进入 **控制台**：https://www.seniverse.com/dashboard

### 2.1 免费版下单

1. 控制台首页 → 找到 **产品管理 / 我的 API 产品**
2. 点 **添加新产品**
3. 产品类型选 **免费版**（0 元，永久有效）
4. 确认下单

> 不下单也能拿到私钥（心知注册完就有基础配额），但**显式下单一个免费版产品是最稳的做法** —— 控制台里能看到明确的额度，用量也直观。

### 2.2 复制私钥

下单完成后，在 **产品管理** 页面能看到你的 **API 密钥**，形如：

```
公钥 UID: u3fxxxxxxxxxxxxxxx
私钥 KEY: Sxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

- **私钥（KEY）** = 你在 URL 里 `key=` 参数要填的东西 → **本项目用这个**
- **公钥（UID）** = 用于"公钥签名"验证方式，请求里只带签名不带私钥，更安全

> 🔒 **私钥安全**：
> - 私钥 = 你的账户凭据，谁拿到都能用你的额度刷请求
> - 填在配网页面的密码框里，别写进公开仓库（**推 GitHub 前一定要搜一遍 `key = "` 和 `S` 开头的长串**）
> - 泄露了就去控制台重置，旧私钥立即失效

**查看/修改私钥的官方说明**：
https://seniverse.yuque.com/hyper_data/api_v3/gc03wk

## 3. 城市参数（location）怎么填

`location` 参数支持多种格式，**推荐顺序**：

| 写法 | 示例 | 说明 |
|---|---|---|
| **拼音（最稳）** | `beijing` | 所有城市都支持，本项目默认用法 |
| 城市中文名 | `北京` | 部分小城市支持不全 |
| 城市 ID | `WX4FBXXFKE4F` | 最精确，官方推荐优先用 |
| 省市组合 | `北京朝阳` | 精确到区 |
| 经纬度 | `39.93:116.40` | 纬度在前，冒号分隔 |
| IP | `ip` | 自动定位到你当前 IP 所在城市 |

> 📌 **本项目配网页面填的是"城市代码"**，直接填 `beijing` / `shanghai` / `hangzhou` 这种拼音即可。
> 如果拼音查不到（比如某些县级市），去官网下载**城市列表**拿城市 ID：
> https://seniverse.yuque.com/hyper_data/api_v3/bwi8100zvwl0koau

**官方城市列表下载页**：https://www.seniverse.com/citylist.html

## 4. 跑通第一个请求（浏览器里先试）

**这一步千万别跳。** 在浏览器里先确认数据能出来，再去调代码，能省掉 90% 的调试时间。

把 `你的私钥` 换成刚才复制的私钥，**直接粘到浏览器地址栏回车**：

### 请求 1：实时天气

```
https://api.seniverse.com/v3/weather/now.json?key=你的私钥&location=beijing&language=zh-Hans&unit=c
```

正常返回（免费版）：

```json
{
  "results": [
    {
      "location": {
        "id": "WX4FBXXFKE4F",
        "name": "北京",
        "country": "CN",
        "path": "北京,北京,中国",
        "timezone": "Asia/Shanghai"
      },
      "now": {
        "text": "多云",
        "code": "4",
        "temperature": "14"
      },
      "last_update": "2026-11-03T10:00:00+08:00"
    }
  ]
}
```

### 请求 2：今日预报

```
https://api.seniverse.com/v3/weather/daily.json?key=你的私钥&location=beijing&language=zh-Hans&unit=c&start=0&days=1
```

正常返回（免费版）：

```json
{
  "results": [
    {
      "location": { "name": "北京", "..." : "..." },
      "daily": [
        {
          "date": "2026-11-03",
          "text_day": "多云",
          "code_day": "4",
          "text_night": "晴",
          "code_night": "0",
          "high": "16",
          "low": "5",
          "wind_direction": "北",
          "wind_direction_degree": "0",
          "wind_speed": "9.66",
          "wind_scale": "3",
          "rainfall": "0.0",
          "precip": "0"
        }
      ],
      "last_update": "2026-11-03T08:00:00+08:00"
    }
  ]
}
```

> 👀 **注意**：免费版的 `daily` 里**没有 `humidity` 字段**，别去找了——不是你的问题，是权限限制。

### 参数速查

| 参数 | 值 | 含义 |
|---|---|---|
| `key` | 你的私钥 | 必填 |
| `location` | `beijing` | 必填 |
| `language` | `zh-Hans` | 简体中文，默认就是它 |
| `unit` | `c` | 摄氏度（`f` = 华氏度） |
| `start` | `0` | 从今天开始（`-1` = 从昨天） |
| `days` | `1` | 取几天（免费版最多 3） |

## 5. 常见错误码对照

浏览器里请求失败时，返回的 JSON 会带 `error_code`。对照这张表排查：

| error_code | 含义 | 怎么办 |
|---|---|---|
| `401` | 认证失败 / 私钥无效 | 检查私钥有没有复制错（常见是带了空格、少了字符、复制成了公钥 UID） |
| `403` | 权限不足 | 用的接口不在你的套餐里（免费版调生活指数接口就是这个错） |
| `404` | 接口地址错 | 检查是不是漏了 `.json` 或路径拼错 |
| `429` | 访问超限 | 免费版 1 次/秒、10 万次/月。检查是不是死循环在请求 |
| `500` | 服务端异常 | 心知自己挂了，等一会儿重试 |

**完整错误码表**：https://seniverse.yuque.com/hyper_data/api_v3/ofoyw2

## 7. 本项目的取数逻辑（对应代码）

代码在 `main/weather.c` 的 `weather_fetch()`：

```
① 请求 now.json
   → 解析 results[0].now.text        → w_text      天气现象
   → 解析 results[0].now.temperature → w_temp      实时气温
   ★ 这一步拿不到 text 就直接失败返回（说明私钥/城市错了）

② 请求 daily.json (days=1)
   → 解析 results[0].daily[0].high    → w_high      今日最高温
   → 解析 results[0].daily[0].low     → w_low       今日最低温
   → 解析 results[0].daily[0].wind_direction → w_wind 风向
   → 解析 results[0].daily[0].wind_scale     → w_wind 风力等级
                                          （拼成 "东南3级"）
   ★ 不请求 humidity —— 免费版没有这个权限
```

**为什么是两次请求？** 因为心知把"实时数据"和"预报数据"放在两个接口里。`now.json` 免费版只有 3 个字段，想要温区和风向就得再打一次 `daily.json`。

**为什么刷新间隔设 15 分钟？** 免费版 1 次/秒、10 万次/月。15 分钟一次 = 每天 96 次 = 每月约 2880 次，离上限很远，但数据也够新。

**界面上会看到什么**：

```
时钟页底部：  多云  23°C        北3级
              ↑天气   ↑气温      ↑风向风力

天气详情页：
  beijing 多云
  23°C          12~23°C
  北3级
  更新19:20
```

## 8. 排错流程（照着走）

板子上天气页显示"暂无数据"或"正在获取天气"，按这个顺序查：

**第 1 步：确认私钥本身有效**
浏览器打开第 4 节那个 now.json 链接。
- 出 JSON → 私钥没问题，继续第 2 步
- 出错误码 → 回第 5 节对照错误码表

**第 2 步：确认城市参数对**
把 `location=beijing` 换成你自己的城市拼音试试。免费版只支持 370 个主要城市，如果你住的小城查不到，**这是正常限制**，换用最近的地级市或经纬度。

**第 3 步：看串口日志**
`idf.py monitor` 输出里找 `weather` 标签：

```
I (12345) weather: 解析失败        → JSON 结构变了，或返回的不是 JSON（多半是私钥错）
W (12345) weather: 心知返回异常     → 私钥/城市不对
I (12345) weather: 多云 14°C  北3级  今日 5~16°C   → 成功
```

**第 4 步：网络层问题**
如果日志里连 `weather` 标签都没出现，说明 HTTP 请求就没发出去，重点查：
- **时间对上了吗**？HTTPS 校验证书有效期，时间不对（差超过几分钟）必失败。**SNTP 必须排在 HTTPS 之前**
- WiFi 连上了吗？看串口有没有打印 IP 地址
