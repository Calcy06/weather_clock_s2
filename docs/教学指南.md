> **零基础版**。不需要你会 C 语言，不需要你懂单片机，只要你会复制粘贴、会用终端。

## 读之前：这份教程怎么用

### 你不需要准备什么

| 你可能担心的 | 实际情况 |
|---|---|
| 不会 C 语言 | 代码全部给你，你要做的是**复制、粘贴、编译、看结果**。每段代码都告诉你它干什么 |

| 怕烧板子 | 照着接线表接不会烧。真正会烧的情况我在⚠️里标出来了 |

### 核心原则：一次只加一个模块

这是**本篇最重要的方法论**。整个项目分 10 个阶段，每个阶段做完都**必须看到效果**再往下走。

为什么？因为如果你一次把所有代码全写完再编译，出了错你根本不知道是哪里的问题。
一个阶段一个阶段来，出错只需要怀疑**刚才加的那段代码**。

> 📌 **卡住了就停在上一步，不要往下走。** 上一步没验证过，后面出的错你分不清是谁的锅。

### 术语表（看不懂词先查这里）

| 术语 | 大白话解释 |
|---|---|
| **GPIO** | 板子上的一根根"针脚"，你可以控制它输出高/低电平，或读取外部电平 |
| **烧录 / Flash** | 把编译好的程序写进板子的 Flash 芯片，掉电不丢。每次改代码都要重新烧 |
| **串口 / 终端 / Monitor** | 板子通过 USB 跟你电脑"说话"的通道。**调试时最重要的信息来源** |
| **I2C** | 一种只用两根线（SDA 数据 + SCL 时钟）连接多个设备的通信方式。你的 OLED 屏就用它 |
| **帧缓冲（FB）** | 内存里的一块区域，先在里面把整屏画面拼好，再一次发给屏幕。避免逐字发送导致闪烁 |
| **NVS** | ESP32 上的"小型数据库"，存在 Flash 里，掉电不丢。用来存 WiFi 密码等配置 |
| **API** | 网站提供的数据接口，按格式发请求就返回数据。本项目用来获取天气 |
| **私钥（API Key）** | 调用天气 API 的"密码"，证明这个请求是你发的 |
| **MQTT** | 一种很轻量的消息协议，手机发消息、设备收消息。本项目用它做远程控制 |
| **SoftAP** | 板子自己开一个 WiFi 热点，手机连上它来配置 |
| **编译** | 把你写的 C 代码变成板子能执行的机器码 |
| **固件** | 编译出来的、要烧进板子的程序文件 |

### 屏幕怎么认（两种都长一样，区别在接口）

```
I2C 四针（本项目用这个）        SPI 七针（本项目不用）
    ┌─────────┐                    ┌─────────┐
    │ VCC     │                    │ VCC     │
    │ GND     │                    │ GND     │
    │ SDA     │                    │ SCL     │
    │ SCL     │                    │ D0 (SCL)│
    └─────────┘                    │ D1 (SDA)│
   4 个引脚                        │ RES     │
                                   │ DC      │
                                   │ CS      │
                                   └─────────┘
                                   7 个引脚
```

**如果是 7 针的**：去跟卖家确认能不能切到 I2C 模式（多数模块背面有焊点/电阻跳线），
或者换一块四针的。本教程只覆盖 I2C 版。

## 0.2 认识你的板子

ESP32-S2-DevKitC-1 的布局：

```
        ┌──────────────────────────────┐
        │      ┌──┐  USB               │
        │      │  │  ═══════════════   │  ← USB 口（烧录 + 供电都走这里）
        │      └──┘                    │
        │                              │
        │  ┌────┐                ┌────┐│
        │  │BOOT│                │RST ││  ← BOOT(GPIO0) 和 RST 复位键
        │  └────┘                └────┘│
        │                              │
  3V3 ●─┤                              ├─● GND
  GPIO ●─┤                              ├─● GPIO
   ...  │       ESP32-S2 芯片           │
  GPIO ●─┤                              ├─● GPIO
   ...  │                              │
        └──────────────────────────────┘
        ← 左右两排共 38 个排针 →
```

**关键引脚知识**（这些必须记住，接错会出怪问题）：

| 引脚 | 用途 | 能不能用 |
|---|---|---|
| **GPIO19 / GPIO20** | USB D- / D+ | ❌ **绝对不能用**，接了 USB 就不识别了 |
| **GPIO26 ~ GPIO32** | 接内部 Flash（SPI） | ❌ **绝对不能用**，接了板子就启动不了 |
| GPIO0 | BOOT 键 + strapping | ⚠️ 本项目用它做"停止闹钟"键，接按键可以 |
| GPIO45 / GPIO46 | strapping（上电电平决定启动模式） | ⚠️ 别接会输出高电平的东西 |
| GPIO1 / GPIO2 | 串口 TX/RX | ⚠️ 能当普通 IO，但会占用调试串口 |
| **GPIO3 ~ GPIO18, GPIO21, GPIO33~GPIO37, GPIO38~GPIO44** | 普通 IO | ✅ 随便用 |

**本项目的引脚规划**（照这个接）：

| 用途 | GPIO | 说明 |
|---|---|---|
| OLED SDA | **GPIO8** | 数据线 |
| OLED SCL | **GPIO9** | 时钟线 |
| 蜂鸣器信号 | **GPIO5** | 高电平响 |
| BOOT 键 | GPIO0 | 板载按键，本项目做"停闹钟 / 长按清 WiFi" |

> 为什么选 8/9/5？因为它们是普通 IO、不冲突、且在板子排针上有标注，好插。

## 0.3 接线

### 接线表（对着插，插完再核对一遍）

```
┌──────────────┬──────────────┬──────────────────┐
│  OLED 引脚   │  接到板子     │  杜邦线颜色建议   │
├──────────────┼──────────────┼──────────────────┤
│ VCC          │ 3V3          │ 红色             │
│ GND          │ GND          │ 黑色             │
│ SDA          │ GPIO8        │ 黄色             │
│ SCL          │ GPIO9        │ 蓝色             │
└──────────────┴──────────────┴──────────────────┘

┌──────────────┬──────────────┐
│ 蜂鸣器引脚   │  接到板子    │
├──────────────┼──────────────┤
│ VCC / +      │ GPIO5        │
│ GND / -      │ GND          │
└──────────────┴──────────────┘
```

### 蜂鸣器接线注意

**模块型**（带电路板，印有 VCC GND I/O 或 SIG）：
```
GPIO5 ──→ 模块的 I/O 或 SIG 脚
GND   ──→ 模块的 GND 脚
3V3   ──→ 模块的 VCC 脚（有些模块标 - 号，用 GND 供电即可）
```
按模块丝印接，别猜。

**裸件型**（只有两个针，无电路板）：
```
GPIO5 ──[蜂鸣器]── GND     （长脚是正极）
```
⚠️ **GPIO 直接驱动力很弱**（最大约 20mA）。3.3V 小蜂鸣器能响但声音小；
5V 蜂鸣器要么声音小，要么响都不响。想响得痛快，加一个三极管驱动：

```
GPIO5 ──[1kΩ电阻]──→ 三极管基极(B)
蜂鸣器+ ── 三极管集电极(C)
GND ── 三极管发射极(E)
```
（NPN 三极管，如 S8050 / 2N2222。新手先用模块型，省事。）

### 接线自检清单（插完照这个查）

- [ ] OLED 的 VCC 接的是 **3V3**，不是 5V（5V 可能烧屏）
- [ ] SDA 对 GPIO8，SCL 对 GPIO9 —— **没有接反**
- [ ] 蜂鸣器 + 接 GPIO5，- 接 GND
- [ ] 没有东西接在 GPIO19/20 或 GPIO26~32
- [ ] 杜邦线插紧了（松了会出现"时好时坏"的灵异现象）
- [ ] USB 线是**数据线**（能传文件的那种）

## 1.2 确认板子能连上电脑

插上 USB，然后：

```bash
ls /dev/ttyUSB* /dev/ttyACM*
```

**你应该看到**：`/dev/ttyUSB0`

> 📌 **你的板子就是 `ttyUSB0`**（走板载 CP210x 这颗 USB 转串口芯片）。
> 如果哪天改成走 S2 原生 USB 直连，名称会变成 `ttyACM0`。
> **以 `ls` 打印出来的为准**，记下来 —— 后面所有 `-p` 参数都用它。
>
> 两个都空 → 说明系统没认到设备，往下看 ②③④ 的排查。

### 如果看不到设备（这是最常见的坎）

按顺序排查：

**① 换 USB 线**（一半的问题在这里）
**② 换 USB 口**（VMware 用户优先插 USB 2.0 口，USB 3.0 有时不通）
**③ 虚拟机没拿到设备**

VMware 用户：

```
虚拟机菜单 → 可移动设备 → 找到 "Silicon Labs CP210x" 或 "Espressif USB JTAG/serial"
→ 点"连接(与主机断开)"
```

VirtualBox 用户：

```
设备菜单 → USB → 勾选你的设备
```

**④ 装驱动**（Linux 一般不需要，直接识别）

**⑤ 权限问题**（ttyUSB0 属于 `dialout` 组，不加组会报 `Permission denied: '/dev/ttyUSB0'`）：

```bash
sudo usermod -a -G dialout $USER
```

然后**注销重登录**（不重登不生效）。

**⑥ 确认一下是不是已经被别的程序占了**：

```bash
sudo lsof /dev/ttyUSB0
```

有输出就是被占用了（比如上次的 `idf.py monitor` 没退干净、或 ModemManager 抓着不放）。
关掉占用者；如果是 ModemManager，直接禁掉：

```bash
sudo systemctl stop ModemManager
sudo systemctl disable ModemManager
```

| 操作 | 方法 |
|---|---|
| 退出 monitor | `Ctrl + ]`（**不是** Ctrl+C，Ctrl+C 是中断，会让程序停下来） |

- monitor 里看到乱码：波特率不对，一般是 `idf.py monitor` 自动设置的，如果手动用别的工具，波特率是 **115200**。

# 第 2 章 点亮 OLED 屏幕

**目标**：屏幕上出现一行字。这是你第一次和 OLED 对话。

## 2.1 先搞懂 I2C 是什么

I2C 是一种"一根总线挂多个设备"的通信方式，只用两根线：

```
        ┌─────────┐
        │  ESP32  │
        │   S2    │
        └──┬───┬──┘
           │   │
        SDA│   │SCL          SDA = 数据线
           │   │              SCL = 时钟线
     ┌─────┴───┴─────┐
     │               │
  ┌──┴───┐       ┌───┴──┐
  │OLED  │       │传感器│     每个设备有唯一"地址"
  │0x3C  │       │0x76  │     SSD1306 通常是 0x3C
  └──────┘       └──────┘
```

关键点：
- **地址**：同一根总线上每个设备有唯一地址。SSD1306 绝大多数是 `0x3C`，少数是 `0x3D`
- **上拉电阻**：SDA/SCL 需要上拉到 VCC。**多数 OLED 模块板上自带**，不用你接；
  如果你用的是裸 OLED 芯片（没有电路板），必须自己接 4.7kΩ 上拉电阻

## 2.2 ESP-IDF v6.0 的 I2C 驱动变了

老教程里的 `driver/i2c.h` 在 v6.0 已经废弃，现在用 `driver/i2c_master.h`。

**思路变化**：以前是"初始化端口 → 直接操作"，现在是"先建总线 → 再往总线上挂设备"。

```c
// 1) 建总线（GPIO8/9，开内部上拉）
i2c_master_bus_config_t bus_cfg = {
    .i2c_port = I2C_NUM_0,
    .sda_io_num = 8,              /* ← 你的 SDA */
    .scl_io_num = 9,              /* ← 你的 SCL */
    .clk_source = I2C_CLK_SRC_DEFAULT,
    .glitch_ignore_cnt = 7,
    .flags.enable_internal_pullup = true,
};
i2c_new_master_bus(&bus_cfg, &bus);

// 2) 往总线上挂一个设备（OLED，地址 0x3C，400kHz）
i2c_device_config_t dev_cfg = {
    .dev_addr_length = I2C_ADDR_BIT_LEN_7,
    .device_address = 0x3C,
    .scl_speed_hz = 400000,
};
i2c_master_bus_add_device(bus, &dev_cfg, &dev);

// 3) 发命令：首字节 0x00 表示"后面都是命令"，0x40 表示"后面是显存数据"
uint8_t cmd[] = {0x00, 0xAE, 0xAF};      // 关显示、再开显示
i2c_master_transmit(dev, cmd, sizeof(cmd), 100);
```

> 💡 **记住那个"控制字节"**：SSD1306 通过 I2C 传输时，第一个字节是控制符：
> `0x00` = 命令，`0x40` = 数据。这是 SSD1306 的协议规定，写死就行。

### 写第一个程序

打开 `main/main.c`，**全部替换**成下面内容：

```c
#include <stdio.h>
#include <string.h>

#include "freertos/FreeRTOS.h"
#include "freertos/task.h"

#include "driver/i2c_master.h"
#include "esp_log.h"

#define PIN_SDA    8
#define PIN_SCL    9
#define OLED_ADDR  0x3C

static const char *TAG = "oled";

/* SSD1306 128x64 上电初始化序列 */
static const uint8_t s_init[] = {
    0xAE,        /* 关显示 */
    0xD5, 0x80,  /* 时钟分频 */
    0xA8, 0x3F,  /* 多路复用比 = 64 行 */
    0xD3, 0x00,  /* 显示偏移 */
    0x40,        /* 起始行 */
    0x8D, 0x14,  /* ★ 电荷泵开（漏了这条 90% 全黑） */
    0x20, 0x00,  /* 水平寻址 */
    0xA1,        /* 段重映射 */
    0xC8,        /* COM 反向扫描 */
    0xDA, 0x12,  /* COM 引脚配置 */
    0x81, 0xCF,  /* 对比度 */
    0xD9, 0xF1,  /* 预充电周期 */
    0xDB, 0x40,  /* VCOMH */
    0xA4,        /* 显示跟随 RAM */
    0xA6,        /* 正常显示 */
    0x2E,        /* 关滚动 */
    0xAF,        /* 开显示 */
};

void app_main(void)
{
    /* 1) 建 I2C 总线 */
    i2c_master_bus_config_t bus_cfg = {
        .i2c_port = I2C_NUM_0,
        .sda_io_num = PIN_SDA,
        .scl_io_num = PIN_SCL,
        .clk_source = I2C_CLK_SRC_DEFAULT,
        .glitch_ignore_cnt = 7,
        .flags.enable_internal_pullup = true,
    };
    i2c_master_bus_handle_t bus;
    ESP_ERROR_CHECK(i2c_new_master_bus(&bus_cfg, &bus));

    /* 2) 探测屏幕在不在（0x3C 找不到就试 0x3D） */
    uint8_t addr = OLED_ADDR;
    if (i2c_master_probe(bus, addr, 100) != ESP_OK) {
        if (i2c_master_probe(bus, 0x3D, 100) == ESP_OK) {
            addr = 0x3D;
        } else {
            ESP_LOGE(TAG, "I2C 上找不到 SSD1306，检查接线！");
            return;
        }
    }
    ESP_LOGI(TAG, "SSD1306 已找到，地址 0x%02X", addr);

    /* 3) 挂设备 */
    i2c_device_config_t dev_cfg = {
        .dev_addr_length = I2C_ADDR_BIT_LEN_7,
        .device_address = addr,
        .scl_speed_hz = 400000,
    };
    i2c_master_dev_handle_t dev;
    ESP_ERROR_CHECK(i2c_master_bus_add_device(bus, &dev_cfg, &dev));

    /* 4) 发初始化序列 */
    uint8_t cmd[40];
    cmd[0] = 0x00;
    memcpy(&cmd[1], s_init, sizeof(s_init));
    vTaskDelay(pdMS_TO_TICKS(50));
    ESP_ERROR_CHECK(i2c_master_transmit(dev, cmd, sizeof(s_init) + 1, 100));
    ESP_LOGI(TAG, "初始化完成");

    /* 5) 往显存写数据：设置窗口 = 全屏，然后发 1024 字节 0xFF（全亮） */
    const uint8_t win[] = {0x00, 0x21, 0x00, 127, 0x22, 0x00, 7};
    ESP_ERROR_CHECK(i2c_master_transmit(dev, win, sizeof(win), 100));

    uint8_t data[1025];
    data[0] = 0x40;                       /* 后续是数据 */
    memset(&data[1], 0xFF, 1024);         /* 全 1 = 全亮 */
    for (;;) {
        ESP_ERROR_CHECK(i2c_master_transmit(dev, data, sizeof(data), 500));
        vTaskDelay(pdMS_TO_TICKS(1000));
    }
}
```

# 第 3 章 显示中文和数字（自己做字库）

**目标**：屏幕上能显示"晴"、"23"这样的字符。

> 📌 **本章开始要拆成多个文件**（第 2 章只有一个 `main.c`，装不下字库 + 绘图）。

## 3.1 为什么不用现成字库

- 现成中文字库常常 200KB+，塞不进 Flash 分区
- 格式和你的显存布局对不上，还要写转换代码
- 想加字/改字很麻烦

**我们的做法**：用电脑把字渲染成点阵，生成 C 数组。格式自己定，想加字随时加。

## 3.2 定数据格式

```
每个字 16×16 像素
行优先，每行 2 字节，MSB 在左，1 = 点亮
一个汉字 = 32 字节
```

举例，"晴"字左上角那一片的二进制：

```
................
...####.........
..#....#........
..#....#........
..#....#........
..#....#........
...####.........
................
```

第一行 `................` → 字节 `0x00, 0x00`
第二行 `...####.........` → 字节 `0x1E, 0x00`

这个格式**和 SSD1306 显存能对上**，省掉一次转换。

# 第 4 章 画出完整时钟界面（先不联网）

**目标**：用假数据把四个页面画出来。**先不管数据从哪来，界面先对。**

## 4.1 帧缓冲

**不要在画每个字的时候直接发 I2C** —— 太慢，而且会闪烁。

正确做法：**先在 RAM 里拼好一整屏（1024 字节），最后一次性推给屏幕。**

```c
static uint8_t s_fb[128 * 64 / 8];        /* 1KB */

/* 点亮 (x,y)：算出它在哪个字节的哪个 bit */
static inline void fb_set(int x, int y, bool on)
{
    if ((unsigned)x >= 128 || (unsigned)y >= 64) return;   /* 越界保护 */
    uint8_t *p = &s_fb[((y >> 3) * 128) + x];   /* 第几页、第几列 */
    uint8_t mask = (uint8_t)(1u << (y & 7));   /* 页内第几个 bit */
    if (on) *p |= mask; else *p &= ~mask;
}
```

这个布局和 SSD1306 显存**完全一致**，推屏时直接 `memcpy` 发走，不用重排。

> 💡 **这就是第 1 章那个全屏点亮能工作的原因**：`0xFF` 填充 1024 字节，每个 bit 都是 1，
> 所以每个像素都亮。

## 4.2 绘图函数

**第 1 层：清屏 + 画点**

**第 3 层：贴字模**

```c
void gfx_blit(int x, int y, int w, int h, const uint8_t *packed)
{
    int bpr = (w + 7) / 8;                    /* 每行字节数 */
    for (int row = 0; row < h; row++) {
        int py = y + row;
        if ((unsigned)py >= 64) continue;      /* 越界保护 */
        const uint8_t *line = packed + row * bpr;
        for (int col = 0; col < w; col++) {
            if (line[col >> 3] & (0x80 >> (col & 7))) {
                fb_set(x + col, py, true);
            }
        }
    }
}
```

**第 4 层：文字（按码点自动选字体）**

```c
static const uint8_t *pick_glyph(uint32_t cp, const ui_font_t **font)
{
    const uint8_t *g = ui_font_glyph(&font_ascii_8x16, cp);
    if (g) { *font = &font_ascii_8x16; return g; }   /* ASCII 8px 宽 */
    g = ui_font_glyph(&font_cn_16x16, cp);
    if (g) { *font = &font_cn_16x16; return g; }     /* 汉字 16px 宽 */
    *font = &font_ascii_8x16;
    return ui_font_glyph(&font_ascii_8x16, '?');     /* 缺字显示问号 */
}

int gfx_text_max(int x, int y, int maxw, const char *utf8)
{
    int x0 = x;
    const char *p = utf8;
    while (*p) {
        uint32_t cp = ui_utf8_next(&p);
        const ui_font_t *f;
        const uint8_t *g = pick_glyph(cp, &f);
        /* ★ 同时限制"调用方给的宽度"和"屏幕右边界" */
        if (x + f->w > x0 + maxw || x + f->w > 128) break;
        gfx_blit(x, y, f->w, f->h, g);
        x += f->w;
    }
    return x - x0;
}
```

> ⚠️ **我第一版忘了限制屏幕右边界**，只限制了调用方给的 `maxw`。
> 结果如果调用方给了一个超过屏幕的宽度，字就画到屏幕外去了。
> 这个 bug 是单元测试抓出来的，肉眼不一定看得出来。

**第 5 层：大号数字（时间用）**

# 第 5 章 连 WiFi + 网络对时

**目标**：屏幕显示真实时间，自动走秒。

## 5.1 WiFi 是事件驱动的

**不要写成死循环等待**：

```c
/* ❌ 错误示范 */
while (!connected) { vTaskDelay(100); }      /* 会卡死整个事件循环 */
```

正确做法：**注册事件回调，连上了 IDF 会通知你**。

```c
static void wifi_event_handler(void *arg, esp_event_base_t base,
                               int32_t id, void *data)
{
    if (base == WIFI_EVENT && id == WIFI_EVENT_STA_START) {
        esp_wifi_connect();                        /* 开始连接 */
    }
    else if (base == WIFI_EVENT && id == WIFI_EVENT_STA_DISCONNECTED) {
        /* ★ 用 esp_timer 延迟 3 秒再重连，不要在回调里立刻重连 */
        esp_timer_start_once(s_retry_timer, 3000);
    }
    else if (base == IP_EVENT && id == IP_EVENT_STA_GOT_IP) {
        ip_event_got_ip_t *e = (ip_event_got_ip_t *)data;
        ESP_LOGI(TAG, "已获取 IP: " IPSTR, IP2STR(&e->ip_info.ip));
        start_sntp();                              /* ★ 拿到 IP 才能对时 */
    }
}
```

### 为什么重连要延迟 3 秒

路由器的 DHCP 还没释放完，你立刻重连大概率再失败，然后又立刻重连 → **死循环刷屏，把 DHCP 服务打挂**。

延迟 3 秒给路由器喘息机会。

> ⚠️ **事件回调里绝对不能 `vTaskDelay`** —— 会阻塞事件循环，其他事件全卡住。

## 5.2 SNTP 对时

```c
#include "esp_sntp.h"

void start_sntp(void)
{
    esp_sntp_setoperatingmode(ESP_SNTP_OPMODE_POLL);
    esp_sntp_setservername(0, "ntp.aliyun.com");   /* 国内快 */
    esp_sntp_setservername(1, "cn.pool.ntp.org");
    esp_sntp_setservername(2, "pool.ntp.org");
    esp_sntp_init();
}
```

对时是**异步**的，调用完不会立刻拿到时间。判断方法：

```c
time_t t = time(NULL);
if (t > 1600000000) {        /* 2020-09-13 之后 = 对上了 */
    /* 时间有效 */
}
```

## 5.3 时区（POSIX 格式，符号是反的）

```c
setenv("TZ", "CST-8", 1);   /* ★ 东八区写 CST-8，不是 CST+8 */
tzset();

time_t now = time(NULL);
struct tm tmv;
localtime_r(&now, &tmv);     /* 线程安全版 */
```

> ⚠️ **POSIX 时区字符串的符号意思是"你要减去多少"**，所以东八区写 `-8`。
> 写成 `CST+8` 会得到 UTC-8（纽约时间），这是超级常见的坑。

```c
#include <string.h>
#include <time.h>

#include "freertos/FreeRTOS.h"
#include "freertos/task.h"

#include "esp_event.h"
#include "esp_log.h"

#include "esp_sntp.h"
#include "esp_timer.h"
#include "esp_wifi.h"
#include "nvs_flash.h"

#include "app_data.h"
#include "gfx.h"
#include "ssd1306.h"
#include "ui.h"

/* ====== 只需要改这两行 ====== */
#define WIFI_SSID   "你的WiFi名"
#define WIFI_PASS   "你的WiFi密码"

static const char *TAG = "clock";

static bool s_connected;
static int64_t s_last_try;      /* 上次尝试重连的时刻(us) */

/* ---------- 事件回调：只做"记状态"，绝不在里面等 ---------- */
static void on_event(void *arg, esp_event_base_t base, int32_t id, void *data)
{
    if (base == WIFI_EVENT && id == WIFI_EVENT_STA_START) {
        esp_wifi_connect();
    } else if (base == WIFI_EVENT && id == WIFI_EVENT_STA_DISCONNECTED) {
        wifi_event_sta_disconnected_t *e = (wifi_event_sta_disconnected_t *)data;
        s_connected = false;
        g_data.wifi_connected = false;
        ESP_LOGW(TAG, "WiFi 断开 (reason=%d)", e->reason);
    } else if (base == IP_EVENT && id == IP_EVENT_STA_GOT_IP) {
        ip_event_got_ip_t *e = (ip_event_got_ip_t *)data;
        ESP_LOGI(TAG, "已获取 IP: " IPSTR, IP2STR(&e->ip_info.ip));
        s_connected = true;
        g_data.wifi_connected = true;

        /* 有网了才开始对时 —— 顺序很重要，不能提前 */
        esp_sntp_setoperatingmode(ESP_SNTP_OPMODE_POLL);
        esp_sntp_setservername(0, "ntp.aliyun.com");
        esp_sntp_setservername(1, "cn.pool.ntp.org");
        esp_sntp_init();
    }
}

/* 对时成功的回调 */
static void on_time_synced(struct timeval *tv)
{
    (void)tv;
    ESP_LOGI(TAG, "时间已同步");
}

void app_main(void)
{
    /* 1) NVS：WiFi 驱动要用它存校准数据，必须先初始化 */
    esp_err_t err = nvs_flash_init();
    if (err == ESP_ERR_NVS_NO_FREE_PAGES || err == ESP_ERR_NVS_NEW_VERSION_FOUND) {
        ESP_ERROR_CHECK(nvs_flash_erase());
        ESP_ERROR_CHECK(nvs_flash_init());
    }

    /* 2) 屏幕 + 数据 */
    data_init();
    ESP_ERROR_CHECK(ssd1306_init());

    /* 3) 时区：东八区是 CST-8（符号是反的！）*/
    setenv("TZ", "CST-8", 1);
    tzset();

    /* 4) WiFi 三步初始化 */
    ESP_ERROR_CHECK(esp_netif_init());
    ESP_ERROR_CHECK(esp_event_loop_create_default());
    esp_netif_create_default_wifi_sta();

    wifi_init_config_t ic = WIFI_INIT_CONFIG_DEFAULT();
    ESP_ERROR_CHECK(esp_wifi_init(&ic));

    esp_event_handler_register(WIFI_EVENT, ESP_EVENT_ANY_ID, on_event, NULL);
    esp_event_handler_register(IP_EVENT, IP_EVENT_STA_GOT_IP, on_event, NULL);

    /* 5) 填 WiFi 账号密码并启动 */
    wifi_config_t wc = {0};
    strncpy((char *)wc.sta.ssid, WIFI_SSID, sizeof(wc.sta.ssid) - 1);
    strncpy((char *)wc.sta.password, WIFI_PASS, sizeof(wc.sta.password) - 1);
    wc.sta.threshold.authmode = WIFI_AUTH_WPA2_PSK;   /* 开放式 WiFi 改成 WIFI_AUTH_OPEN */

    ESP_ERROR_CHECK(esp_wifi_set_mode(WIFI_MODE_STA));
    ESP_ERROR_CHECK(esp_wifi_set_config(WIFI_IF_STA, &wc));
    esp_wifi_set_ps(WIFI_PS_NONE);        /* 关省电，不然时间会跳 */
    ESP_ERROR_CHECK(esp_wifi_start());

    esp_sntp_set_time_sync_notification_cb(on_time_synced);

    /* 6) 主循环：1 秒刷一次屏 */
    for (;;) {
        int64_t now_us = esp_timer_get_time();

        /* 断线重连：3 秒重试一次，在循环里做，不阻塞回调 */
        if (!s_connected && now_us - s_last_try > 3 * 1000 * 1000) {
            s_last_try = now_us;
            ESP_LOGI(TAG, "尝试重连 WiFi...");
            esp_wifi_connect();
        }

        time_t now = time(NULL);
        struct tm tmv;
        localtime_r(&now, &tmv);

        /* 年份 > 2020 说明已经对过时了（没对时的时候是 1970 年）*/
        if (tmv.tm_year > 120) {
            g_data.tm = tmv;
            g_data.time_valid = true;
        }

        ui_render(UI_PAGE_CLOCK);        /* 画到帧缓冲 */
        ssd1306_flush(gfx_fb());         /* 推给屏幕 */

        vTaskDelay(pdMS_TO_TICKS(1000));
    }
}
```

## 6.4 要懂的点

### HTTP 客户端流程

`init → open → fetch_headers → 判断 status_code → 循环 read → close → cleanup`

工程里封装成了 `http_get_text(url, ua, buf, len)`（`main/net_http.c`）。

**关键点**：`esp_http_client_read` 要**循环读**，一次读不完。

```c
size_t total = 0;
while (total + 1 < buflen) {
    int r = esp_http_client_read(c, buf + total, buflen - 1 - total);
    if (r <= 0) break;                  /* 读完了 */
    total += (size_t)r;
}
buf[total] = '\0';
```

> ⚠️ 我第一版只读了一次，JSON 被截断，解析必然失败。

### HTTPS 证书

```c
esp_http_client_config_t cfg = {
    .url = url,
    .crt_bundle_attach = esp_crt_bundle_attach,   /* 用 IDF 内置证书包 */
    .disable_auto_redirect = true,
```

### JSON 解析

用 IDF 自带的 cJSON，一层层剥：

```
results[0].now.text          → 天气现象
results[0].now.temperature   → 实时气温
results[0].daily[0].high      → 今日最高温
results[0].daily[0].low       → 今日最低温
results[0].daily[0].wind_direction → 风向
results[0].daily[0].wind_scale     → 风力等级
```

### 温度是字符串不是数字

```json

```

```c
#include <stdio.h>
#include <string.h>

#include "cJSON.h"
#include "esp_crt_bundle.h"
#include "esp_http_client.h"
#include "esp_log.h"

#include "app_data.h"

#define SEN_KEY  "你的私钥"
#define SEN_LOC  "beijing"

static const char *TAG = "weather";
static char s_buf[2048];

static bool http_get(const char *url)
{
    esp_http_client_config_t cfg = {
        .url = url,
        .timeout_ms = 8000,
        .crt_bundle_attach = esp_crt_bundle_attach,
    };
    esp_http_client_handle_t c = esp_http_client_init(&cfg);
    if (c == NULL) {
        return false;
    }

    if (esp_http_client_open(c, 0) != ESP_OK) {
        esp_http_client_cleanup(c);
        return false;
    }

    esp_http_client_fetch_headers(c);
    int status = esp_http_client_get_status_code(c);

    size_t total = 0;
    while (total + 1 < sizeof(s_buf)) {
        int r = esp_http_client_read(c, s_buf + total, sizeof(s_buf) - 1 - total);
        if (r <= 0) {
            break;
        }
        total += (size_t)r;
    }
    s_buf[total] = '\0';

    esp_http_client_close(c);
    esp_http_client_cleanup(c);

    if (status != 200) {
        ESP_LOGW(TAG, "HTTP %d", status);
        return false;
    }
    return total > 0;
}

static void get_str(const cJSON *o, const char *k, char *dst, size_t n)
{
    const cJSON *it = cJSON_GetObjectItem(o, k);
    if (cJSON_IsString(it) && it->valuestring != NULL) {
        strncpy(dst, it->valuestring, n - 1);
        dst[n - 1] = '\0';
    }
}

bool weather_fetch(void)
{
    char url[256];
    char text[24] = {0}, temp[8] = {0};
    char low[8] = {0}, high[8] = {0};
    char wdir[16] = {0}, wscale[8] = {0};

    snprintf(url, sizeof(url),
             "https://api.seniverse.com/v3/weather/now.json?key=%s&location=%s&language=zh-Hans&unit=c",
             SEN_KEY, SEN_LOC);
    if (!http_get(url)) {
        return false;
    }
    ESP_LOGI(TAG, "原始 JSON: %s", s_buf);

    cJSON *root = cJSON_Parse(s_buf);
    if (root == NULL) {
        ESP_LOGE(TAG, "JSON 解析失败");
        return false;
    }
    cJSON *r0 = cJSON_GetArrayItem(cJSON_GetObjectItem(root, "results"), 0);
    cJSON *now = cJSON_GetObjectItem(r0, "now");
    get_str(now, "text", text, sizeof(text));
    get_str(now, "temperature", temp, sizeof(temp));
    cJSON_Delete(root);

    if (text[0] == '\0') {
        ESP_LOGE(TAG, "没取到天气，检查私钥/城市（免费版常见 401）");
        return false;
    }

    snprintf(url, sizeof(url),
             "https://api.seniverse.com/v3/weather/daily.json?key=%s&location=%s"
             "&language=zh-Hans&unit=c&start=0&days=1",
             SEN_KEY, SEN_LOC);
    if (http_get(url)) {
        root = cJSON_Parse(s_buf);
        if (root != NULL) {
            r0 = cJSON_GetArrayItem(cJSON_GetObjectItem(root, "results"), 0);
            cJSON *d0 = cJSON_GetArrayItem(cJSON_GetObjectItem(root, "daily"), 0);
            if (d0 != NULL) {
                get_str(d0, "low", low, sizeof(low));
                get_str(d0, "high", high, sizeof(high));
                get_str(d0, "wind_direction", wdir, sizeof(wdir));
                get_str(d0, "wind_scale", wscale, sizeof(wscale));
            }
            cJSON_Delete(root);
        }
    }

    strncpy(g_data.w_text, text, sizeof(g_data.w_text) - 1);
    strncpy(g_data.w_temp, temp, sizeof(g_data.w_temp) - 1);
    strncpy(g_data.w_low, low[0] ? low : "--", sizeof(g_data.w_low) - 1);
    strncpy(g_data.w_high, high[0] ? high : "--", sizeof(g_data.w_high) - 1);
    if (wdir[0] != '\0') {
        snprintf(g_data.w_wind, sizeof(g_data.w_wind), "%s%s级", wdir, wscale);
    } else {
        g_data.w_wind[0] = '\0';
    }
    g_data.weather_valid = true;

    ESP_LOGI(TAG, "%s %s°C  %s  今日 %s~%s°C", text, temp, g_data.w_wind, low, high);
    return true;
}
```

```
第 1 步  浏览器打开 6.3 的链接
         ├─ 出 JSON      → 私钥没问题，继续
         └─ 出错误码     → 401=私钥错(复制带空格/少了字符/复制成了公钥)
                          403=免费版调了付费接口
                          429=频率超限

第 2 步  location 换另一个城市拼音试
         └─ 小城查不到 → 正常，免费版只支持 370 个主要城市

第 3 步  看串口日志，找 weather 标签
         ├─ "解析失败"        → 返回的不是预期 JSON
         ├─ "心知返回异常"     → 私钥/城市不对
         ├─ 成功打印天气       → 去查 UI 显示逻辑
         └─ 连 weather 都没有 → HTTP 没发出去
                               → 查 WiFi 连没连、时间对没对

第 4 步  确认 WiFi 已连（串口有 IP）
第 5 步  确认时间已对（串口有对时日志）
         └─ 没对时 → HTTPS 必失败，这是 90% "天气取不到" 的真因
```

## 7.4 表单数据要自己解码

手机提交的是 `application/x-www-form-urlencoded`：

```
ssid=MyWiFi&pass=12345678&senkey=Sxxxx&senloc=beijing
```

三种编码必须自己处理：

| 字符 | 含义 | 解码成 |
|---|---|---|
| `+` | 空格 | `' '` |
| `%20` | 空格 | `' '` |
| `%E9%99%8D` | UTF-8 单字节 | 逐字节还原 |

### url_decode 核心代码

```c
static int hex_val(char c)
{
    if (c >= '0' && c <= '9') return c - '0';
    if (c >= 'a' && c <= 'f') return c - 'a' + 10;
    if (c >= 'A' && c <= 'F') return c - 'A' + 10;
    return -1;
}

void url_decode(char *dst, const char *src, size_t dstlen)
{
    size_t o = 0;
    for (size_t i = 0; src[i] && o + 1 < dstlen; i++) {
        if (src[i] == '+') {
            dst[o++] = ' ';
        } else if (src[i] == '%' && hex_val(src[i+1]) >= 0 && hex_val(src[i+2]) >= 0) {
            dst[o++] = (char)(hex_val(src[i+1]) * 16 + hex_val(src[i+2]));
            i += 2;
        } else {
            dst[o++] = src[i];
        }
    }
    dst[o] = '\0';
}
```

### 字段提取：前缀误命中的坑

```c
/* ❌ 错误：查 "ssid" 会误命中 "ssid_manual" */
if (strstr(body, "ssid")) { ... }

/* ✅ 正确：key 后面必须紧跟 '=' */
int form_get_str(const char *body, const char *key, char *out, size_t outlen)
{
    size_t klen = strlen(key);
    for (const char *p = body; (p = strstr(p, key)) != NULL; p += klen) {
        if (p[klen] == '=') {                      /* ★ 这行是灵魂 */
            const char *v = p + klen + 1;
            const char *e = strchr(v, '&');
            size_t n = e ? (size_t)(e - v) : strlen(v);
            /* 截断 + url_decode */
            return 1;
        }
    }
    return 0;
}
```

```c
static void html_escape(char *dst, size_t dstlen, const char *src)
{
    size_t o = 0;
    for (size_t i = 0; src[i] && o + 7 < dstlen; i++) {
        switch (src[i]) {
        case '&':  memcpy(dst + o, "&amp;",  5); o += 5; break;
        case '<':  memcpy(dst + o, "&lt;",   4); o += 4; break;
        case '>':  memcpy(dst + o, "&gt;",   4); o += 4; break;
        case '"':  memcpy(dst + o, "&quot;", 6); o += 6; break;
        default:   dst[o++] = src[i]; break;
        }
    }
    dst[o] = '\0';
}
```

## 8.4 ⚠️ 最大的坑：topic/data 不以 `\0` 结尾

MQTT 协议里没有"字符串结束符"的概念。直接 `printf("%s", e->data)`
会**读到缓冲区后面的随机内存**，打印乱码或者崩。

**必须按长度拷贝，手动补 `'\0'`**：

```c
case MQTT_EVENT_DATA: {
    char topic[64], payload[64];
    memcpy(topic,   e->topic,  e->topic_len);   topic[e->topic_len]   = '\0';
    memcpy(payload, e->data,   e->data_len);   payload[e->data_len]   = '\0';
    handle_command(topic, payload);
    break;
}
```

## 8.5 ⚠️ 第二个坑：中文消息按字节截断会切坏 UTF-8

消息缓冲只有 28 字节，超了要截断。但汉字在 UTF-8 里占 3 字节，
硬切会切成半个汉字 → 显示问号。

**解决办法**：截断后调用尾部修剪，把残缺的半个汉字删掉。

```c
void str_utf8_trim_tail(char *s)
{
    size_t n = strlen(s);
    if (n == 0) return;

    /* 从结尾向前找序列起始字节（10xxxxxx 是续字节） */
    size_t i = n;
    while (i > 0 && ((unsigned char)s[i - 1] & 0xC0) == 0x80) i--;
    if (i == 0) { s[0] = '\0'; return; }

    /* s[i-1] 是起始字节，看它声明的序列长度 */
    unsigned char lead = (unsigned char)s[i - 1];
    int seqlen = 1;
    if      (lead >= 0xF0) seqlen = 4;
    else if (lead >= 0xE0) seqlen = 3;
    else if (lead >= 0xC0) seqlen = 2;

    /* 序列不完整（被截断）就把整个残缺序列删掉 */
    if (i - 1 + seqlen > n) s[i - 1] = '\0';
}
```

用法：

```c
char buf[28];
size_t n = len < sizeof(buf) - 1 ? len : sizeof(buf) - 1;
memcpy(buf, text, n);
buf[n] = '\0';
str_utf8_trim_tail(buf);        /* ★ 截断后必须修剪 */
```

## 8.9 完整代码（可直接编译）

新建 `main/mqtt_app.c`，贴进去：

```c
#include <stdio.h>
#include <string.h>

#include "esp_log.h"
#include "esp_wifi.h"
#include "mqtt_client.h"

#include "app_data.h"
#include "form.h"

static const char *TAG = "mqtt";
static char s_topic_ctrl[48];
static char s_topic_report[48];

/* 收到消息的统一入口 */
static void on_mqtt(void *args, esp_event_base_t base, int32_t id, void *data)
{
    esp_mqtt_event_handle_t e = (esp_mqtt_event_handle_t)data;

    switch (id) {
    case MQTT_EVENT_CONNECTED:
        ESP_LOGI(TAG, "已连接 broker");
        esp_mqtt_client_subscribe(e->client, s_topic_ctrl, 1);
        esp_mqtt_client_publish(e->client, s_topic_report, "online", 0, 1, 0);
        break;

    case MQTT_EVENT_DATA: {
        /* topic / data 都不以 \0 结尾，必须按长度拷 */
        char topic[64] = {0};
        char payload[64] = {0};
        int tl = e->topic_len < (int)sizeof(topic) - 1 ? e->topic_len : (int)sizeof(topic) - 1;
        int dl = e->data_len < (int)sizeof(payload) - 1 ? e->data_len : (int)sizeof(payload) - 1;
        memcpy(topic, e->topic, tl);
        memcpy(payload, e->data, dl);
        str_utf8_trim_tail(payload);          /* 截断可能切坏汉字 */

        ESP_LOGI(TAG, "收到 [%s] %s", topic, payload);

        /* 简单指令：前缀匹配 */
        if (strncmp(payload, "msg ", 4) == 0) {
            strncpy(g_data.msg[0], payload + 4, sizeof(g_data.msg[0]) - 1);
            g_data.msg_count = 1;
            g_data.msg_serial++;              /* 渲染任务看到它就弹屏 */
        } else if (strcmp(payload, "beep") == 0) {
            ESP_LOGI(TAG, "→ 让蜂鸣器响（第 9 章接上）");
        }
        break;
    }

    case MQTT_EVENT_DISCONNECTED:
        ESP_LOGW(TAG, "断开，SDK 会自动重连");
        break;

    default:
        break;
    }
}

/* 假设 WiFi 已经连上 */
void mqtt_start(void)
{
    /* 用 MAC 后三字节做主题前缀，避免和别人撞车 */
    uint8_t mac[6] = {0};
    esp_wifi_get_mac(WIFI_IF_STA, mac);
    snprintf(s_topic_ctrl, sizeof(s_topic_ctrl), "wc/%02X%02X%02X/control",
             mac[3], mac[4], mac[5]);
    snprintf(s_topic_report, sizeof(s_topic_report), "wc/%02X%02X%02X/report",
             mac[3], mac[4], mac[5]);

    esp_mqtt_client_config_t cfg = {
        .broker.address.uri = "mqtt://broker.emqx.io:1883",
        .credentials.client_id = "wc-s2-demo",
    };
    esp_mqtt_client_handle_t c = esp_mqtt_client_init(&cfg);
    esp_mqtt_client_register_event(c, ESP_EVENT_ANY_ID, on_mqtt, NULL);
    esp_mqtt_client_start(c);

    ESP_LOGI(TAG, "订阅主题：%s", s_topic_ctrl);
}
```

**编译前必须做 8.1**（加 `espressif/mqtt` 依赖），`REQUIRES` 里再加 `mqtt`。

**在 `main.c` 里的调用时机**：拿到 IP 之后调 `mqtt_start()`，**不要在 `app_main` 开头调**

# 第 9 章 蜂鸣器闹钟

## 9.1 有源 vs 无源

| 类型 | 特点 | 本项目 |
|---|---|---|
| **有源** | 内部自带振荡电路，**给高电平就响** | ✅ 用这个 |
| 无源 | 需要 PWM 给频率，能播放音乐 | ❌ 本项目不用 |

有源蜂鸣器只要通断 GPIO：

```c

{
    gpio_set_level(PIN_BUZZER, on ? 1 : 0);
}
```

> ⚠️ **GPIO 推流有限**（约 20mA）。3.3V 小蜂鸣器能直接接；5V 蜂鸣器声音小或响不了，
> 需要三极管驱动。

## 9.2 GPIO 配置

```c
gpio_config_t io = {
    .pin_bit_mask = 1ULL << PIN_BUZZER,
    .mode = GPIO_MODE_OUTPUT,
    .pull_up_en = GPIO_PULLUP_DISABLE,
    .pull_down_en = GPIO_PULLDOWN_DISABLE,
    .intr_type = GPIO_INTR_DISABLE,
};
gpio_config(&io);
gpio_set_level(PIN_BUZZER, 0);        /* 默认不响 */
```

## 9.3 闹钟状态机

```
空闲 ──(到设定时间)──→ 响铃 ──(按BOOT 或 满60秒)──→ 空闲
```

三个要点：

```c
/* ① 判断到点：时、分对上，且秒 < 2（避免一分钟内重复触发） */
if (t->tm_hour == alarm_h && t->tm_min == alarm_m && t->tm_sec < 2) { ... }

/* ② "今天已响过"标记，否则那一分钟会重复触发 */
static int last_fired_day = -1;
if (t->tm_yday != last_fired_day) { ... }

/* ③ 响铃期间每秒翻转一次电平，形成"滴滴"效果 */
if (ringing && (t->tm_sec % 2 == 0)) buzzer_set(true);
else buzzer_set(false);
```

## 9.4 按键停止

```c
/* 边沿触发：按下瞬间才执行，按住不放不会重复 */
bool key = (gpio_get_level(PIN_KEY) == 0);
if (key && !last_key && alarm_ringing()) {
    alarm_stop();
}
last_key = key;
```

> ⚠️ **没做边沿触发的话，按住不放会反复执行。**

## 9.5 ✅ 验证

把闹钟设成当前时间 +1 分钟，等到点响，按 BOOT 键立刻停。

## 9.6 ⚠️ 坑

- **没做 NTP 对时**：时间从 1970 年开始，闹钟永远不响
- 按键检测要**边沿触发**
- 闹钟响满 60 秒要自动停（避免忘关）

## 9.7 完整代码（两步走，先验硬件再写逻辑）

**第一步：硬件自测**。把 `main/main.c` 整个换成下面这份，烧进去就该听到"每 3 秒响一下"：

```c
#include <stdbool.h>

#include "driver/gpio.h"
#include "esp_log.h"
#include "freertos/FreeRTOS.h"
#include "freertos/task.h"

#define PIN_BUZZER  5

static const char *TAG = "buzzer";

static void buzzer_init(void)
{
    gpio_config_t io = {
        .pin_bit_mask = 1ULL << PIN_BUZZER,
        .mode = GPIO_MODE_OUTPUT,
        .pull_up_en = GPIO_PULLUP_DISABLE,
        .pull_down_en = GPIO_PULLDOWN_DISABLE,
        .intr_type = GPIO_INTR_DISABLE,
    };
    gpio_config(&io);
    gpio_set_level(PIN_BUZZER, 0);      /* 上电先别响 */
}

static void buzzer_set(bool on)
{
    gpio_set_level(PIN_BUZZER, on ? 1 : 0);
}

void app_main(void)
{
    buzzer_init();

    /* 硬件自测：每 3 秒响 300ms */
    for (;;) {
        buzzer_set(true);
        vTaskDelay(pdMS_TO_TICKS(300));
        buzzer_set(false);
        ESP_LOGI(TAG, "响了一声");
        vTaskDelay(pdMS_TO_TICKS(2700));
    }
}
```

听到响声 → **接线对、蜂鸣器是好的、GPIO5 能驱动**。听不到就回去查接线（见 9.6），
别急着写闹钟逻辑。

**第二步：换成闹钟逻辑**。把 `buzzer_init()` / `buzzer_set()` 保留，把 `app_main` 换回你自己的，
然后在主循环里每秒调一次：

```c
#include <stdbool.h>
#include <time.h>

#include "driver/gpio.h"
#include "esp_log.h"
#include "freertos/FreeRTOS.h"
#include "freertos/task.h"

#define PIN_BUZZER  5
#define PIN_KEY     0        /* 板载 BOOT 键 */

static const char *TAG = "buzzer";

static void buzzer_init(void)
{
    gpio_config_t out = {
        .pin_bit_mask = 1ULL << PIN_BUZZER,
        .mode = GPIO_MODE_OUTPUT,
        .pull_up_en = GPIO_PULLUP_DISABLE,
        .pull_down_en = GPIO_PULLDOWN_DISABLE,
        .intr_type = GPIO_INTR_DISABLE,
    };
    gpio_config(&out);
    gpio_set_level(PIN_BUZZER, 0);      /* 上电先别响 */

    gpio_config_t in = {
        .pin_bit_mask = 1ULL << PIN_KEY,
        .mode = GPIO_MODE_INPUT,
        .pull_up_en = GPIO_PULLUP_ENABLE,   /* BOOT 键按下是低电平 */
        .intr_type = GPIO_INTR_DISABLE,
    };
    gpio_config(&in);
}

static void buzzer_set(bool on)
{
    gpio_set_level(PIN_BUZZER, on ? 1 : 0);
}

/* 闹钟：到点后一直响，按键停止 */
static void alarm_check(const struct tm *t)
{
    static bool ringing;
    static int last_min = -1;

    if (!ringing && t->tm_hour == 6 && t->tm_min == 30 && last_min != t->tm_min) {
        ringing = true;
        last_min = t->tm_min;
        ESP_LOGI(TAG, "闹钟响！按 BOOT 停止");
    }
    if (ringing) {
        buzzer_set(true);
        if (gpio_get_level(PIN_KEY) == 0) {
            ringing = false;
            buzzer_set(false);
            ESP_LOGI(TAG, "已停止");
        }
    }
}
```

`alarm_check(&g_data.tm)` 放在渲染循环里，`g_data.tm` 是第 5 章那个每秒更新一次的时间。

> ⚠️ **为什么不用中断做按键**：有源蜂鸣器响的时候电流突变，GPIO 中断容易被干扰误触发。
> 1 秒轮询一次按键足够用，而且代码简单到不会出错。

# 第 10 章 打磨

功能都通了，剩下的是"好不好用"：

### 1. 页面轮播

`page_sec` 秒切一页，**时钟页出现两次**（人看时间的频率最高）：

```c
static const int SEQ[] = {UI_PAGE_CLOCK, UI_PAGE_WEATHER, UI_PAGE_CLOCK, UI_PAGE_BILI};
```

### 2. 消息弹屏优先

用 `msg_serial` 自增触发，10 秒后自动回主界面：

```c
if (g_data.msg_serial != seen_serial) {
    seen_serial = g_data.msg_serial;
    page = UI_PAGE_MSG;
    msg_deadline = now + 10;      /* 10 秒后恢复 */
}
```

### 3. 没配 B站 就跳过 B站页

别让用户看到一页"暂无数据"：

```c
if (SEQ[*idx] == UI_PAGE_BILI && g_cfg.bili_uid[0] == '\0' && g_cfg.bili_bv[0] == '\0') {
    continue;
}
```

### 4. 长时间连不上自动回配网

换路由器后板子不会变砖：

```c
for (int i = 0; i < 40 && !wifi_connected(); i++) {     /* 最多等 20 秒 */
    vTaskDelay(pdMS_TO_TICKS(500));
}
if (!wifi_connected()) {
    enter_prov_mode();
}
```

### 5. 长按 BOOT 5 秒清 WiFi 配置

主动换网络用：

```c
if (key) {
    if (++key_hold >= 5) {          /* 渲染任务 1 秒跑一次，5 = 5 秒 */
        g_cfg.wifi_ssid[0] = '\0';
        g_cfg.wifi_pass[0] = '\0';
        cfg_save();
        esp_restart();
    }
} else {
    key_hold = 0;
}
```

### 6. 亮度可调

`ssd1306_set_contrast()`，夜里别晃眼。

| 换路由器连不上 | 配置还是旧的 | 长按 BOOT 5 秒清配置 |

# 附录 B FAQ

**Q1：我完全没学过 C，能做完吗？**
能。所有代码都给你，你要做的是复制、粘贴、编译、看结果。每段代码上面都写了它干什么。
做完你对"代码是怎么变成硬件动作的"会有直觉认识，这比背语法有价值。

**Q2：一定要用虚拟机吗？能不能在 Windows 上装？**
ESP-IDF 有 Windows 版，但 Linux 下遇到问题能搜到的解决方案多得多，且和文档一致。
推荐用虚拟机。ESP32-S2 的 USB 设备在 VMware/VirtualBox 里做一次直通就能用。

**Q3：屏幕点亮了但显示反了（上下颠倒/左右镜像）？**
初始化序列里 `0xA1`↔`0xA0` 控制左右，`0xC8`↔`0xC0` 控制上下。换着试。

**Q4：蜂鸣器不响？**
① 确认是有源蜂鸣器 ② 确认 + 接 GPIO5、- 接 GND ③ 万用表量 GPIO5 有没有 3.3V 输出
④ 裸件可能是电流不够，换模块型

**Q5：心知天气私钥填了还是没数据？**
按这个顺序：① 浏览器打开请求 URL 看返回 ② 串口有没有 `weather` 标签日志
③ WiFi 连没连 ④ **时间对没对**（90% 是这个原因）

**Q6：MQTT 用什么 App？**
手机用 MQTTX（iOS/Android 都有），电脑也能装。broker 填 `test.ranye-iot.net`，
主题填 `wc/你的设备MAC后三字节/chat`，发 `msg 你好`。

**Q7：能换成别的天气 API 吗？**
能。代码里只依赖 `http_get_text()` 这一个函数。换个 URL、改 JSON 解析路径就行。
免费无密钥的还可以用 Open-Meteo，但天气描述是英文码，要自己做中文映射。

**Q8：烧录后要重新配网吗？**
不用。配置存在 NVS 里，掉电不丢。只有长按 BOOT 5 秒（或换了 WiFi 环境连不上）才需要重配。

# 附录 E 多文件工程怎么组织

> **什么时候看这个**：第 2 章你只有一个 `main.c`，没问题。
> 到**第 3 章加字库、第 4 章加绘图**，代码会变几百行，必须拆成多个文件。
> 这里讲清楚 IDF 的规矩，拆文件时不会卡。

## E.1 IDF 的"组件"模型

ESP-IDF 里，**每个组件（component）就是一个目录 + 一个 `CMakeLists.txt`**。
`main/` 本身也是一个组件，只是名字特殊（它总是被编译）。

本项目全部代码放在 `main/` 里，所以只有**一个** `CMakeLists.txt` 要改：

```
weather_clock_s2/
├── CMakeLists.txt        ← 顶层，只写 project(...)，基本不用动
└── main/
    ├── CMakeLists.txt    ← ★ 加 .c 文件就改这里
    ├── main.c
    ├── gfx.c / gfx.h
    ├── ui.c / ui.h
    └── fonts/
        ├── font.c / font.h
        └── font_cn_16x16.c
```

## E.2 `main/CMakeLists.txt` 长什么样

```cmake
idf_component_register(
    SRCS                     # ← 要编译的 .c 文件，一个都不能漏
        "main.c"
        "gfx.c"
        "ui.c"
        "fonts/font.c"
        "fonts/font_cn_16x16.c"
    INCLUDE_DIRS             # ← 头文件搜索路径（#include 时去哪找）
        "."
        "fonts"
    REQUIRES                 # ← 用到哪些 IDF 组件（esp_wifi、nvs_flash…）
        nvs_flash
        esp_wifi
        esp_event
        esp_netif
        esp_driver_i2c
        esp_driver_gpio
        json
        mqtt
)
```

三个字段的含义，用大白话说：

| 字段 | 作用 | 漏了会怎样 |
|---|---|---|
| `SRCS` | 告诉编译器"这些 .c 都要编译" | `undefined reference to 'gfx_text'`（找不到函数实现） |
| `INCLUDE_DIRS` | 告诉编译器"头文件在这些目录里" | `fatal error: gfx.h: No such file or directory` |
| `REQUIRES` | 告诉链接器"我要用 IDF 的哪些模块" | `fatal error: esp_wifi.h: No such file or directory` |

> 完整版（本项目最终的 16 个 .c）见工程里实际的 `main/CMakeLists.txt`，
> 你写到哪一章就加到哪一章需要的文件，不用一次抄全。

## E.3 加一个新模块的 3 步

假设你要加一个 `buzzer.c` / `buzzer.h`（蜂鸣器）：

**第 1 步**：在 `main/` 下新建 `buzzer.h`：

```c
#pragma once              /* ← 头文件保护，防止重复包含。每个 .h 第一行都写这个 */

#include <stdbool.h>

/* 只在这里写"别人要用的东西"：函数声明、常量 */
void buzzer_init(int gpio);
void buzzer_beep(int ms);
```

**第 2 步**：新建 `buzzer.c`：

```c
#include "buzzer.h"
#include "driver/gpio.h"

static int s_gpio;        /* static = 只有本文件能看见，外部拿不到 */

void buzzer_init(int gpio) { s_gpio = gpio; /* ... */ }
void buzzer_beep(int ms)   { /* ... */ }
```

**第 3 步**：改 `main/CMakeLists.txt`，在 `SRCS` 里加一行：

```cmake
    SRCS
        "main.c"
        "buzzer.c"        # ← 新增
```

然后 `idf.py build`。

> 💡 `idf.py build` 会自动检测到 CMakeLists 变了并重新生成构建文件，不用手动 `rm -rf build`。

**在别的文件里用它**，只要 `#include "buzzer.h"`，因为 `.` 已经在 `INCLUDE_DIRS` 里了。

## E.4 头文件里到底该写什么

新手最常见的坑：**在 `.h` 里定义变量**，然后多个 `.c` 都 include 它，链接时报
`multiple definition of 'xxx'`。

规则很简单：

| 放哪 | 写什么 |
|---|---|
| **`.h` 里** | 函数**声明**（`void f(void);`）、`#define` 常量、`struct` 定义、`extern` 变量声明 |
| **`.c` 里** | 函数**实现**、变量的**定义**（真正分配内存的那一份） |

要跨文件共享一个变量（比如本项目的 `g_data` 全局数据），这样写：

```c
/* app_data.h */
#pragma once
#include "..." 
typedef struct { int temp; } app_data_t;
extern app_data_t g_data;      /* ← 声明：只说明"有这么个变量" */
```

```c
/* app_data.c */
#include "app_data.h"
app_data_t g_data;             /* ← 定义：真正分配内存，只能有一处 */
```

## E.5 拆文件报错对照表

| 报错 | 原因 | 解决 |
|---|---|---|
| `undefined reference to 'xxx'` | `.c` 没写进 `SRCS` | 加进 `main/CMakeLists.txt` 的 `SRCS` |
| `xxx.h: No such file or directory` | 头文件路径不对 | 检查 `INCLUDE_DIRS`；或 `#include` 写成 `"fonts/font.h"` |
| `esp_wifi.h: No such file` | `REQUIRES` 缺组件 | 在 `REQUIRES` 里加 `esp_wifi` |
| `multiple definition of 'xxx'` | 在 `.h` 里定义了变量 | `.h` 里改 `extern`，定义搬到某个 `.c` |
| `implicit declaration of function 'xxx'` | 忘了 `#include` 对应头文件 | 加上 `#include "xxx.h"` |
| 改了 CMakeLists 没生效 | 构建缓存 | `idf.py fullclean` 再 `build` |

> ⚠️ **v6.0 特有**：`driver/gpio.h` 和 `driver/i2c_master.h` 现在分别属于
> `esp_driver_gpio` 和 `esp_driver_i2c` 两个组件，**必须写进 REQUIRES**，
> 否则报头文件找不到。v5.x 只写 `driver` 就行，v6 不行了。
